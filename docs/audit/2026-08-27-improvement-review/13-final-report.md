### 新增的 5 条跨方向共性发现

5. **Prompt cache 稳定前缀的脆弱性**——任何重新排序或条件注入都会击穿远端 KV cache（miss 比 hit 贵 2-3 倍）。本项目**当前未启用客户端 cache**（`llm_client.py` 无 `cache_control` 标记），所以现在"击穿"零成本，但**未来启用时是隐患**。
6. **Semaphore 局部实例架构**（4 处）—— `pipeline.py:441` / `final_summary.py:525` / `final_summary.py:1442` / `location_normalizer.py:553/613`，**任何"全局限流"必须接入 AnalysisService 单例层**，不能直接 patch Semaphore。
7. **checkpoint 全量失效的代价**——13 本老书的 result.json 不会自动获得新字段；要么重新跑（成本太高），要么把新字段做成"可选"（前端容错降级）。
8. **dataclass 扩展窗口期**——这是 B 组审核的关键发现：`AnalysisResult` / `ForeshadowItem` 等 dataclass 加新字段时**必须** `field(default_factory=list)` 或 `= ""`，否则 `from_dict` 白名单构造会因缺键报 `TypeError`。
9. **⚠️ ECharts 6.1 已有 `GanttChart` / `HeatmapChart` / `CustomChart` / `TimelineComponent`**——多个"换库"型建议被证伪，零新依赖即可实现。

- **dataclass 字段扩展窗口期**：所有新字段必须 `field(default_factory=list)` 或 `= ""`，否则 `from_dict` 白名单构造会因缺键报 `TypeError`（来自 B 组审核的关键发现）
- **接入层选择**：跨章校验（#6）和幻觉检测（#33）**不能接入 `validate_response` 回调**——闭包只收到 `response: str`，拿不到 `chapter_content` 和 `knowledge_base`。必须新建 post-parse 阶段。**【修正】但 #6 的 check 2（章号引用）和 check 3（50 类校验）可在 `validate_parsed_analysis(data: dict)` 内实现**——该函数在 `validate_json_response` 闭包内被调用，能访问 `chapter_number`（闭包变量）和 `FORESHADOW_CATEGORY_DEFS`（已 import）；失败走现有温度退火重试链，零架构改动。check 1（角色一致性）和 #33（幻觉检测）才需 post-parse 阶段（需 chapter_content）
- **不要动 `asyncio.Semaphore._value`**：Python 3.10+ 的 `BoundedSemaphore` 只是 release 校验；要动态调窗只能走"重置"或"滑动窗口"路径

### 5.2 前端扩展必读

- **WebView2 兼容**：禁 `backdrop-filter`、快捷键避开 `Ctrl+K`（改 `/` 或 `Ctrl+Shift+F`）、动画用 `transform`/`opacity`
- **设计系统**：所有色值/圆角/阴影必须 `--win-*` 变量；选中态用 `--win-accent`
- **三种切书请求守卫**（`agent.md §6.6`）：seq 计数器 / bookId 快照比对 / finally 条件复位，**新页面手写守卫时参照本节**
- **ECharts 6.1 已含** `GanttChart` / `HeatmapChart` / `CustomChart` / `TimelineComponent`，**零新依赖**

### 5.3 质量保证必读

- **每个 dataclass 新增字段后**：必须新增 1 个 model roundtrip 测试
- **每个新聚合函数后**：必须新增原子写测试（参考 `test_aggregate_atomic.py`）
- **每个新 LLM 字段后**：必须新增 schema 容错测试（缺失字段降级）
- **任何改 prompt 的提交**：必须更新 `agent.md §10` 当前状态章节（项目硬约束）
